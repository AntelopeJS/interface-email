# Attachments

The interface supports four attachment types, each suited to a different source of file data. All types share a common `BaseAttachment` structure and are passed through the `attachments` field of `EmailParams`.

## The `BaseAttachment` Interface

Every attachment type extends `BaseAttachment`, which defines shared metadata fields:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `filename` | `string` | Yes | The filename shown to the recipient |
| `contentType` | `string` | No | MIME type (e.g., `"application/pdf"`) |
| `cid` | `string` | No | Content-ID for inline images (reference in HTML as `cid:yourCid`) |
| `inline` | `boolean` | No | If `true`, embed in the HTML body instead of attaching as a file |

## Attachment Types

### `BufferAttachment`

Use `BufferAttachment` when you have file data in memory as a Node.js `Buffer`. This is common when generating files dynamically or reading from streams.

```ts
import { Send, BufferAttachment } from "@antelopejs/interface-email";

const pdfBuffer = Buffer.from(/* generated PDF data */);

const attachment: BufferAttachment = {
  filename: "report.pdf",
  contentType: "application/pdf",
  content: pdfBuffer,
};

await Send({
  to: "user@example.com",
  subject: "Your Report",
  text: "Please find the attached report.",
  attachments: [attachment],
});
```

### `Base64Attachment`

Use `Base64Attachment` when you have file data encoded as a base64 string. Set the `encoding` field to `"base64"` to distinguish it from a `BufferAttachment`.

```ts
import { Send, Base64Attachment } from "@antelopejs/interface-email";

const attachment: Base64Attachment = {
  filename: "logo.png",
  contentType: "image/png",
  content: "iVBORw0KGgoAAAANSUhEUgAA...",
  encoding: "base64",
};

await Send({
  to: "user@example.com",
  subject: "Brand Assets",
  text: "Logo attached.",
  attachments: [attachment],
});
```

### `PathAttachment`

Use `PathAttachment` to attach a file from the local filesystem by its path. The email provider reads the file at send time.

```ts
import { Send, PathAttachment } from "@antelopejs/interface-email";

const attachment: PathAttachment = {
  filename: "data-export.csv",
  contentType: "text/csv",
  path: "/tmp/exports/data-export-2026.csv",
};

await Send({
  to: "analyst@example.com",
  subject: "Data Export",
  text: "The requested export is attached.",
  attachments: [attachment],
});
```

### `UrlAttachment`

Use `UrlAttachment` to attach a file from a remote URL. The email provider fetches the file from the URL at send time.

```ts
import { Send, UrlAttachment } from "@antelopejs/interface-email";

const attachment: UrlAttachment = {
  filename: "handbook.pdf",
  contentType: "application/pdf",
  url: "https://cdn.example.com/docs/handbook-v3.pdf",
};

await Send({
  to: "new-hire@example.com",
  subject: "Employee Handbook",
  text: "Please review the attached handbook.",
  attachments: [attachment],
});
```

## Inline Images

Inline attachments embed images directly in the HTML body using Content-ID references. Set `inline` to `true` and assign a `cid` value, then reference it in your HTML with the `cid:` protocol.

```ts
import { Send, BufferAttachment } from "@antelopejs/interface-email";

const logoBuffer = Buffer.from(/* logo image data */);

await Send({
  to: "user@example.com",
  subject: "Welcome",
  html: `
    <div>
      <img src="cid:company-logo" alt="Company Logo" />
      <h1>Welcome to our platform!</h1>
    </div>
  `,
  attachments: [
    {
      filename: "logo.png",
      contentType: "image/png",
      content: logoBuffer,
      cid: "company-logo",
      inline: true,
    },
  ],
});
```

> **Note:** Check `GetCapabilities().features.inlineAttachments` to confirm the provider supports inline images.

## Multiple Attachments

The `attachments` field accepts an array, so you can mix different attachment types in a single email:

```ts
import { Send } from "@antelopejs/interface-email";

await Send({
  to: "client@example.com",
  subject: "Project Deliverables",
  text: "All deliverables are attached.",
  attachments: [
    {
      filename: "proposal.pdf",
      contentType: "application/pdf",
      path: "/documents/proposal.pdf",
    },
    {
      filename: "mockup.png",
      contentType: "image/png",
      url: "https://cdn.example.com/mockups/v2.png",
    },
    {
      filename: "notes.txt",
      contentType: "text/plain",
      content: Buffer.from("Meeting notes for the project kickoff."),
    },
  ],
});
```

## The `Attachment` Union Type

The `Attachment` type is a union of all four attachment interfaces:

```ts
type Attachment = BufferAttachment | Base64Attachment | PathAttachment | UrlAttachment;
```

When constructing attachments dynamically, TypeScript narrows the type based on the presence of distinguishing fields (`content` with `encoding`, `path`, or `url`).
